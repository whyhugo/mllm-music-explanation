# mllm-music

Fine-tuning **Qwen2-Audio-7B-Instruct** with LoRA for automated music captioning,
evaluated on the [MusicCaps](https://huggingface.co/datasets/google/MusicCaps) benchmark.

## Overview

This project investigates whether a general-purpose audio-language model can be
efficiently adapted to the music captioning task using parameter-efficient fine-tuning.

**Architecture**

```
Audio (.wav, 16 kHz)
       │
       ▼
 ┌─────────────┐     ┌──────────────────────┐
 │ Audio Tower │────▶│ Multi-Modal Projector │ ← unfrozen
 │  (Whisper)  │     └──────────────────────┘
 └─────────────┘               │
  (frozen)                     ▼
                      ┌────────────────┐
                      │  Qwen2-7B LLM  │ ← LoRA on q/k/v/o_proj
                      └────────────────┘
                               │
                               ▼
                      "A mellow piano ballad
                       with soft female vocals..."
```

**Training strategy**
- Freeze audio tower and base LLM weights
- Unfreeze multi-modal projector (audio → LLM bridge)
- Inject LoRA (r=16) into LLM attention layers: q/k/v/o_proj
- Trainable parameters: ~16.8 M / 7.77 B (0.22%)

## Results

All metrics computed on the same 500-sample holdout set.

| Run | Data | Epochs | Avg Loss | ROUGE-1 | ROUGE-2 | ROUGE-L | BLEU | METEOR | Avg Δ |
|-----|------|--------|----------|---------|---------|---------|------|--------|-------|
| Baseline | — | — | — | 0.5136 | 0.2723 | 0.4113 | 0.2227 | 0.4158 | — |
| exp-001 | 93 | 3 | 8.83 | 0.5802 | 0.3633 | 0.4828 | 0.3185 | 0.5051 | +22.5%† |
| exp-002 | 93 | 5 | 7.99 | 0.5853 | 0.3563 | 0.4770 | 0.3095 | 0.4968 | +20.7%† |
| exp-003 | 503 | 5 | 7.93 | 0.5896 | 0.3715 | 0.4962 | 0.3084 | 0.4964 | +25.9% |
| **exp-004** | **1003** | **10** | **6.73** | eval pending | — | — | — | — | — |

†exp-001/002 evaluated on 93-sample set; not directly comparable.

**Key finding:** Data volume has more impact than hyperparameter tuning.
Going from 93 → 1003 samples dropped avg training loss from ~8.8 to 6.73,
with monotone per-epoch improvement across all 10 epochs (9.06 → 5.39).

## Setup

### 1. Create environment

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r qwen/requirements.txt
```

### 2. Download MusicCaps audio

```bash
# Download ~500 clips (recommended starting point)
python salmonn/download_musiccaps.py --target 700 --workers 3

# Download the full dataset (~5521 clips, ~60% success rate)
python salmonn/download_musiccaps.py --target all
```

### 3. Create train / val split

```bash
python qwen/split_dataset.py                    # 90/10 split, seed=42
python qwen/split_dataset.py --val_ratio 0.15   # custom ratio
python qwen/split_dataset.py --dry_run          # preview without writing
# → data/train.json (900), data/val.json (100)
```

## Training

```bash
# Qwen2-Audio LoRA fine-tuning
python qwen/train_lora_qwen.py

# Monitor with TensorBoard (in a separate terminal)
bash qwen/launch_tb.sh
# then open: http://localhost:6006
```

**TensorBoard metrics logged each epoch:**

| Metric | Description |
|--------|-------------|
| `train/loss` | Training cross-entropy loss |
| `eval/loss` | Validation loss (overfitting indicator) |
| `train/lora_B_rms` | LoRA-B matrix RMS — rises from 0 as model adapts |
| `train/projector_rms` | Multi-modal projector weight magnitude |
| `train/label_ratio` | Fraction of sequence positions used for loss |
| `train/grad_norm` | Pre-clip gradient norm |

## Evaluation

```bash
# Baseline (no LoRA)
python qwen/evaluate_qwen.py \
    --output outputs/eval_baseline.json

# Fine-tuned checkpoint
python qwen/evaluate_qwen.py \
    --lora_path outputs/qwen_musiccaps_finetuned/checkpoint-315 \
    --output outputs/eval_exp003.json

# Compare all experiments
python experiments/compare.py
python experiments/compare.py --detail exp-003
```

## Configuration

Key hyperparameters in `qwen/train_lora_qwen.py`:

| Parameter | Current | Notes |
|-----------|---------|-------|
| `num_train_epochs` | 10 | Loss still declining at ep5 in exp-003 |
| `learning_rate` | 1e-5 | Lower than exp-001 (2e-5) to reduce oscillation |
| `gradient_accumulation_steps` | 8 | Effective batch size = 8 |
| `max_grad_norm` | 0.5 | Gradient clipping |
| `warmup_steps` | 100 | ~10% of total steps |
| LoRA `r` | 16 | Rank; increase to 32 for larger capacity |
| LoRA `target_modules` | q/k/v/o_proj | LLM attention layers only |

## Experiment Tracking

All runs are logged in `experiments/runs.json` with full hyperparameter and
metric records. Use the compare script to view results:

```bash
python experiments/compare.py                  # summary table
python experiments/compare.py --detail exp-003 # full run detail
```
